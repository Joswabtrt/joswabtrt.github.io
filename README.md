# ZENITH STORE

Готовый статический сайт магазина привилегий.

## Загрузка на GitHub
1. Создайте новый репозиторий.
2. Загрузите все файлы из этого архива в корень репозитория.
3. В Settings → Pages включите GitHub Pages.
4. Выберите ветку `main` и папку `/ (root)`.

Сайт использует ZENITH как игровую валюту. Демонстрационный баланс и покупки работают в браузере через localStorage.
